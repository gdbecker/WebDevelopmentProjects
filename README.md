## Projects Overview

### [ASL Zone App](https://github.com/gdbecker/ASLZone)

Inspired by a personal passion for inclusive communication, this ASL learning application was developed using Angular and Firebase to provide a comprehensive platform for studying signs and testing knowledge through interactive quizzes. The project features a robust authentication system, category-based learning modules, and a dedicated admin dashboard for managing content and site-wide registration settings. By bridging the gap between modern frontend development and accessibility, ASL Zone offers a streamlined, user-friendly experience for anyone looking to connect with the deaf community.

### [Cat Facts App](https://github.com/gdbecker/next-js-cat-facts)

When I was looking for free APIs to play around with, I'm so glad I stumbled across this cat facts API - just last year my family decided to adopt a kitten (crazy that this is our first family pet and we're all in our twenties!) and I've never thought I'd love cats as much as I do now, so I knew I wanted to make something with this API. I thought this would be a fun way to continue getting more familiar with Next.js, Bootstrap, and SASS together by adding in the main "get" call to grab a random cat fact, as well as add in a small back-end API call of my own to choose a random image for the top of the card (cat-6.jpg is our cat Poppie). I kept the design simple so I could focus more on the back-end functionality and I'm really happy with how this came out!

### [HikingVentures App](https://github.com/gdbecker/HikingVenturesProject)

This is a personal capstone project I made as a challenge to synthesize a lot from what I've been learning hodgepodge on my own. It was a total blast figuring this out and I'm very happy with the result!

Hiking is one of my favorite things to do and I wanted to try making a hiking trail and park database app where you could search and filter, find your new favorite trail to add to your favorites, and keep a record of the best places you've been. AllTrails is one of my go-to hiking trail databases and provided a source of inspiration for this project.

### [Task Manager App](https://github.com/gdbecker/TaskManager)

This project is a dynamic to-do management system built with Python and the Django web framework, featuring a secure authentication system for personalized task tracking. By leveraging REST architecture and local database integration, the application allows users to seamlessly create, manage, and persist their daily objectives through a clean, responsive interface. The development highlights a mastery of core backend logic, including the use of decorators, functional programming methods, and custom middleware to ensure a streamlined and efficient user experience.

### [Writing Tools App](https://github.com/gdbecker/WritingTools)

Writing Tools is a place all writers at any point in their journeys can go to get some new ideas or time themselves for work/breaks to effectively use the constraints they have and keep themselves motivated. The Ideas page includes generators for writing prompts across different genres at the click of a dropdown, as well as for first and last character names. All data is housed in a custom Firebase database. There is also a pomodoro timer on the next page writers can set up with their work and break time preferences, and check marks at the bottom of the screen keep track of how many work/break cycles they completed.
